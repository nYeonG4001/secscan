# SecScan MVP

## 기능 (7개)

1. 인증/인가 — 로그인과 역할 기반 접근 제어. 계정 식별자는 이메일이며, MVP는 내부 계정과 비밀번호 방식으로 구현
2. 프로젝트 관리 — 관리자가 등록, 조회, 수정하고 사용자 접근권한을 부여 또는 해제
3. 소스 등록: MVP에서는 관리자가 ZIP 파일을 업로드한다. 시스템은 업로드된 소스에서 분석 언어를 자동 식별한다. 분석 시 생성한 소스 스냅샷은 MVP 기간 동안 보관한다. Git 저장소와 기관 내부 경로, 스냅샷 자동 정리는 후속 기능으로 둔다.
4. 정적 분석 실행 — 관리자만. 외부 분석 엔진을 연동하고 KISA 49개 기준과 분석 결과를 관리한다. 관리자는 진단 기준을 등록하거나 수정할 수 있다. 실제 탐지는 기간 안에 가능한 많은 항목을 지원
5. 분석 상태 관리 — 대기→진행→완료/실패 (백그라운드 태스크 + 폴링)
6. 결과 조회 — 리스트 + 심각도 필터 + 상세(코드 스니펫 포함)
7. 기본 보안 — 비밀번호 해싱, 권한 없는 접근 차단, path traversal(zip slip) 차단

프로젝트 관리는 등록, 조회, 수정만 지원한다. 프로젝트 삭제는 MVP 범위에서 제외한다.

관리자 분석 소스 뷰어는 E1부터 E7까지의 핵심 작업과 검증을 마친 뒤 시간이 남을 때만 진행하는 선택 작업으로 둔다. MVP 완료 조건에는 포함하지 않는다.

## 화면과 주요 상태 (13개)

화면 설계의 기준은 `docs/design/drafts/secscan-ui-v0.5.pen`이다. 소스 등록과 분석 실행은 독립 화면이 아니라 프로젝트 상세 안의 액션 패널에서 수행한다.

1. 로그인
2. 프로젝트 목록
3. 프로젝트 상세, ADMIN
4. 프로젝트 상세, USER
5. 소스 등록 및 분석 실행 액션 패널, ADMIN
6. 프로젝트 생성 액션 패널, ADMIN
7. 사용자 접근권한 관리 액션 패널, ADMIN
8. 분석 상태
9. 분석 결과, ADMIN
10. 분석 결과, USER
11. 진단 기준 카탈로그, ADMIN
12. 진단 기준 카탈로그, USER
13. 진단 기준 등록 액션 패널, ADMIN

## MVP 제외 (향후 확장 로드맵)

- 대시보드 시각화
- 분석 이력 비교/추이
- 항목별 수정 가이드 연계
- 다국어, 알림, 리포트 PDF 내보내기
- 위 7개 기능 범주에 속하지 않는 나머지 요구사항 전부
