# SecScan MVP

## 기능 (7개)

1. 인증/인가 — 로그인과 역할 기반 접근 제어. 계정 식별자는 이메일 또는 일반 아이디로 정할 수 있으며, MVP는 내부 계정과 비밀번호 방식으로 구현
2. 프로젝트 관리 — 관리자가 등록 + 사용자 접근권한 부여
3. 소스 등록 — MVP에서는 관리자가 파일을 업로드한다. Git 저장소와 기관 내부 경로는 후속 기능으로 둔다.
4. 정적 분석 실행 — 관리자만. 외부 분석 엔진을 연동하고 KISA 49개 기준과 분석 결과를 관리한다. 실제 탐지는 기간 안에 가능한 많은 항목을 지원
5. 분석 상태 관리 — 대기→진행→완료/실패 (백그라운드 태스크 + 폴링)
6. 결과 조회 — 리스트 + 심각도 필터 + 상세(코드 스니펫 포함)
7. 기본 보안 — 비밀번호 해싱, 권한 없는 접근 차단, path traversal(zip slip) 차단

## 화면 (6개)

1. 로그인
2. 관리자 — 프로젝트 관리 (등록 + 사용자 권한 부여)
3. 관리자 — 업로드 + 분석 실행 (프로젝트 선택 포함)
4. 분석 상태 (프로젝트별)
5. 결과 조회 — 리스트 + 필터 + 상세 펼침
6. 진단 기준 카탈로그 — 49개 목록 + 구현 상태 표시

## MVP 제외 (향후 확장 로드맵)

- 대시보드 시각화
- 분석 이력 비교/추이
- 항목별 수정 가이드 연계
- 다국어, 알림, 리포트 PDF 내보내기
- 위 7개 기능 범주에 속하지 않는 나머지 요구사항 전부
