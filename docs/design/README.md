# Design files

## 관리 규칙

- `drafts/`: 작업 중인 디자인 초안
- `secscan-login.pen`: 검토가 끝난 로그인 기준 디자인
- 초안 파일은 버전과 용도를 파일명에 포함한다.
- 최종본이 확정되면 `DESIGN.md`에 기준 파일을 기록한다.
- Pen.dev 문구와 화면은 구현 전에 SecScan 기준으로 정리한다.

## 현재 파일

- `drafts/secscan-login-v0.1.pen`: 로그인 화면 1차 초안

현재 초안에는 Lunaris 템플릿과 영어 문구가 포함되어 있으므로, SecScan 브랜드와 한국어 문구로 교체한 뒤 최종본으로 승격한다.
