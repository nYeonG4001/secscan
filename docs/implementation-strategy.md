# 구현 전략

## 목표

Java, JavaScript, Python 소스코드를 등록하고 정적 보안 분석을 실행한 뒤, 분석 결과를 공통 형식과 KISA 진단 기준으로 저장·조회하는 교육용 SAST 웹 애플리케이션을 완성한다.

## 현재 기준

- 이 문서는 2026-08-26 기준의 개인 구현 전략 초안이다.
- 멘토 답변과 원본 요구사항을 반영한 현재 구현 방향이다.
- 원본 요구사항과 멘토 답변이 우선한다.

## 기술 선택

- 백엔드: Python, FastAPI, SQLAlchemy, Alembic
- 프론트엔드: React, TypeScript, Vite, Tailwind
- 데이터베이스: PostgreSQL
- 실행 환경: Docker Compose
- 분석 방식: 외부 정적 분석 엔진 연동, 필요한 KISA 매핑과 규칙 보완
- 사용자 방식: 웹 브라우저 기반 관리자와 일반 사용자

## 분석 처리 흐름

```text
소스 업로드
→ 프로젝트별 작업영역 생성
→ 언어 확인
→ 정적 분석 엔진 실행
→ 원본 결과 파싱
→ KISA 기준 매핑
→ 공통 결과 정규화
→ Finding 저장
→ 분석 상태 완료 또는 실패
```

## 저장 구조

```text
User
Project
ProjectAccess
Analysis
Finding
KisaCatalog
```

분석 결과에는 진단 항목, 심각도, 신뢰도, 언어, 파일 위치, 메시지, 탐지 근거, 조치 권고, 원본 결과를 저장한다.

## 권한 전략

- 관리자는 프로젝트 관리, 사용자 권한 관리, 소스 등록, 분석 실행을 할 수 있다.
- 일반 사용자는 권한 있는 프로젝트의 분석 상태와 결과를 읽기 전용으로 조회한다.
- 프로젝트, 분석, 결과 조회 시 URL의 식별자만 믿지 않고 저장된 프로젝트 관계와 사용자 권한을 확인한다.
- 상세 오류와 실행 로그는 관리자에게만 노출한다.

## 보안 전략

- 업로드된 소스는 분석 건별 작업영역에 격리한다.
- ZIP 경로 조작과 심볼릭 링크를 검증한다.
- 분석 실행 시간과 자원을 제한한다.
- 외부 입력으로 임의 서버 경로를 직접 열지 않는다. Git 저장소와 기관 내부 경로는 허용 목록과 접근 권한을 검증한다.
- 비인가 프로젝트 자원은 존재 여부가 드러나지 않도록 처리한다.

## 화면 범위

```text
로그인
관리자 프로젝트 관리
소스 업로드와 분석 실행
분석 상태
분석 결과 목록과 상세
KISA 카탈로그
```

각 화면에 정상, 로딩, 빈 결과, 실패, 권한 없음 상태를 설계한다.

## 테스트 전략

- 인증과 역할 권한 테스트
- 프로젝트 접근 권한 테스트
- 업로드 및 ZIP 보안 테스트
- 분석 상태 전환 테스트
- Java, JavaScript, Python 취약 코드와 정상 코드 테스트
- 결과 필드와 KISA 매핑 테스트
- 프론트 핵심 흐름과 상태별 화면 테스트
- 외부 분석 도구와 오픈소스 의존성의 버전, 라이선스, 취약점 점검

## MVP 완료 기준

관리자가 테스트 프로젝트에 소스코드를 등록하고 분석을 실행할 수 있어야 한다. 분석 상태가 관리되어야 하며, 완료 후 권한 있는 사용자가 표준화된 결과를 목록, 필터, 상세 형태로 조회할 수 있어야 한다. 인증, 권한, 파일 처리, 분석 실행 보안과 핵심 테스트가 통과해야 한다.

## 후속 결정 항목

- 기존 6개 KISA 항목의 직접 API 확장 우선순위와 제외 범위는 [ADR-041](adr/041-six-kisa-direct-api-expansion.md) 및 [E5 직접 API 커버리지 확장 계획](epic/e5-kisa-six-code-coverage-expansion.md)을 따른다. 구현 전 원본 요구사항 문서와 다시 대조하며, 구현할 규칙 수의 상한은 정하지 않는다.
- Git 저장소 인증 방식과 기관 내부 경로 허용 범위는 후속 에픽에서 결정
- SEC-010의 세부 검증 명령과 실행 증거

## 확정된 실행 정책

- 프로젝트별로 `PENDING` 또는 `RUNNING` 상태의 분석은 하나만 허용한다. 진행 중인 분석이 있으면 새 분석을 생성하지 않고 409 응답으로 현재 분석 상태를 안내한다. 근거와 상세는 `docs/epic/e1-data-model.md`의 E1-04를 따른다.
