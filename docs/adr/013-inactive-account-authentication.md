# ADR-013: 비활성 계정 인증 정책

## Context

DAR-002는 사용자 데이터에 활성 상태를 저장하도록 요구한다. SEC-002는 인증 정보의 발급, 검증, 만료 정책을 적용하도록 요구하지만, 비활성 계정이 이미 발급받은 토큰을 즉시 차단해야 하는지는 정하지 않는다.

## Decision

사용자 계정은 기본적으로 `active=true`로 생성한다.

- `active=false` 계정은 로그인 요청을 성공시킬 수 없다.
- 보호된 API는 토큰 서명과 만료 시각을 검증한 뒤 DB에서 사용자를 조회해 `active=true`인지 확인한다.
- 비활성 계정의 로그인과 기존 토큰 요청은 계정 상태를 알리지 않는 일반 `401 Unauthorized`로 거부한다.
- MVP는 계정 관리 화면이나 활성 상태 변경 API를 제공하지 않는다. 이 범위는 계정 관리 요구사항이 정해질 때 별도로 결정한다.

## Consequences

- 관리자가 계정을 비활성화하면 만료되지 않은 기존 토큰도 다음 보호 API 요청부터 사용할 수 없다.
- 토큰 검증은 사용자 조회를 포함하므로 완전히 무상태 방식으로 처리하지 않는다.
- 인증 테스트는 활성 계정 로그인, 비활성 계정 로그인 거부, 비활성 전환 뒤 기존 토큰 거부를 포함해야 한다.
