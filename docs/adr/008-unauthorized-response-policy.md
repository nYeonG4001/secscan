# ADR-008: 비인가 프로젝트 자원 응답 정책

## Context

SEC-005와 SEC-006은 요청 식별자만 신뢰하지 않고 저장된 관계와 권한을 확인하며, 비인가 요청에 자원 존재 정보가 불필요하게 노출되지 않도록 요구한다.

## Decision

프로젝트, 분석 실행, 진단 결과처럼 존재 여부가 노출될 수 있는 자원에 대해 사용자가 접근 권한이 없으면 `404 Not Found`로 응답한다. 인증 정보가 없거나 유효하지 않으면 `401 Unauthorized`를 반환한다. 자원 존재 여부와 무관한 관리자 전용 기능에서 인증된 일반 사용자가 역할 권한만 부족한 경우에는 `403 Forbidden`을 반환한다.

## Consequences

- 프로젝트 소속이 아닌 사용자는 다른 프로젝트의 존재 여부를 확인할 수 없다.
- 프로젝트 ID, 분석 ID, Finding ID 직접 조회에도 동일한 정책을 적용해야 한다.
- 라우터별 응답 정책을 흩어지게 구현하지 않고 공통 접근 검증 의존성을 사용한다.
