# ADR-012: 외부 구성요소 보안 관리

## Context

SEC-010은 외부 솔루션 또는 오픈소스 구성요소를 사용할 때 취약점 관리, 라이선스 준수, 버전 관리와 보안 업데이트 방안을 마련하도록 요구한다. SecScan은 외부 정적 분석 도구와 여러 오픈소스 라이브러리를 사용할 수 있으므로 분석 기능 구현과 별도로 구성요소 관리가 필요하다.

## Decision

외부 구성요소를 다음 기준으로 관리한다.

- 의존성 버전은 매니페스트와 잠금 파일로 고정한다.
- 분석 도구와 주요 라이브러리의 이름, 버전, 용도를 문서화한다.
- 릴리스 전 의존성 취약점 점검을 수행하고 결과를 기록한다.
- 사용 라이선스를 확인하고 저장소의 라이선스 정책과 충돌하지 않는지 검토한다.
- 취약 버전이 확인되면 안전한 버전으로 업데이트하고 변경 내용을 기록한다.

## Consequences

- 외부 도구를 사용하더라도 구성요소의 보안 상태와 변경 이력을 설명할 수 있다.
- CI에 취약점과 라이선스 점검을 추가하는 작업이 필요하다.
- 점검 도구가 제공하는 결과와 실제 수정 여부를 구분해 기록해야 한다.
