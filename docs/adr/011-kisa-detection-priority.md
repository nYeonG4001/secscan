# ADR-011: KISA 탐지 우선순위와 매핑 정책

## Context

KISA 49개 항목은 모두 카탈로그로 관리해야 한다. 다만 짧은 개발 기간 안에 모든 항목의 실제 탐지를 구현하기는 어려울 수 있으므로, 외부 분석 도구가 제공하는 결과와 KISA 항목의 연결 기준이 필요하다.

## Decision

- 49개 항목은 카탈로그에 모두 등록한다.
- 실제 탐지는 외부 분석 도구가 지원하고 테스트로 검증할 수 있는 항목부터 최대한 많이 지원한다.
- 탐지 우선순위는 외부 도구 지원 여부, KISA 매핑의 명확성, 지원 언어 수, 테스트 샘플 작성 가능성을 기준으로 정한다.
- 카탈로그에는 항목별 구현 상태를 `지원`, `부분 지원`, `미지원`으로 표시한다.
- 외부 도구의 결과가 KISA 항목으로 연결되지 않으면 결과를 버리지 않고 KISA 매핑 상태를 `미매핑`으로 저장한다.
- 실제 우선순위 목록은 분석 엔진과 규칙을 확인한 뒤 이 ADR에 갱신한다.

## Consequences

- 카탈로그 범위와 실제 탐지 범위를 구분해서 설명할 수 있다.
- 지원하지 않는 항목을 지원하는 것처럼 표시하지 않아 검증 결과가 명확해진다.
- 외부 도구 결과를 보존할 수 있지만, 미매핑 결과를 위한 데이터 필드와 화면 표시가 필요하다.
