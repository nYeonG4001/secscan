# ADR-004: 분석 실행 권한을 관리자로 한정

**Context**: 요구사항 중 일반 사용자의 분석 실행 가능 여부에 대한 해석이 갈릴 수 있음(업로드/실행 관련 요구와 접근통제 요구가 상충 가능). 하나로 해석해서 구현해야 함.

**Decision**: 접근통제(권한 없는 접근 차단) 요구를 우선한다. 코드 업로드와 분석 실행은 관리자만 가능하고, 일반 사용자는 완료된 분석의 결과 조회만 가능하다.

**Alternatives**: 일반 사용자에게도 업로드/실행 허용(기각: 보안 요구사항과 충돌), 둘 다 허용해 혼재(기각: 요구사항 충돌을 방치하면 검수에서 더 위험)

**Consequences**: 화면/API가 단순해짐(업로드+실행이 관리자 화면 하나로 통합) / 이 해석이 맞는지 중간발표에서 확인받을 것
