# ADR-010: 계정 식별자 형식

## Context

SFR-001은 기관에서 관리하는 계정 식별자와 비밀번호를 요구하지만, 식별자를 이메일로 제한하는지 일반 아이디도 허용하는지는 정하지 않았다.

## Decision

MVP는 시스템 내부 계정과 비밀번호 인증으로 구현한다. 계정 식별자는 이메일 형식으로 확정한다. 로그인 API, 로그인 화면, 시드 계정과 검증 규칙은 이메일을 기준으로 일관되게 적용한다.

## Consequences

- 외부 SSO나 OAuth 연동 없이 인증 흐름을 완성할 수 있다.
- 이메일 형식 검증과 중복 방지 규칙을 적용해야 한다.
- 식별자 중복, 비밀번호 해싱, 실패 응답, 로그인 시도 제한을 테스트해야 한다.
