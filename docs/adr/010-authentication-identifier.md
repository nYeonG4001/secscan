# ADR-010: 계정 식별자 형식

## Context

SFR-001은 기관에서 관리하는 계정 식별자와 비밀번호를 요구하지만, 식별자를 이메일로 제한하는지 일반 아이디도 허용하는지는 정하지 않았다.

## Decision

MVP는 시스템 내부 계정과 비밀번호 인증으로 구현한다. 계정 식별자는 이메일 또는 일반 아이디 중 하나를 선택할 수 있도록 고정하지 않는다. 실제 구현에서는 하나의 형식을 선택하고, 로그인 API와 화면의 라벨 및 검증 규칙을 일관되게 적용한다.

## Consequences

- 외부 SSO나 OAuth 연동 없이 인증 흐름을 완성할 수 있다.
- 식별자 형식 선택은 구현 초기의 별도 작업으로 기록한다.
- 식별자 중복, 비밀번호 해싱, 실패 응답, 로그인 시도 제한을 테스트해야 한다.
