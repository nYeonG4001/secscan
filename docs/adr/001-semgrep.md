# ADR-001: Semgrep 채택

**Context**: Java, JavaScript, Python 3개 언어를 지원하는 SAST가 필요하다. 자체 엔진을 만들지, 외부 분석 엔진을 연동할지는 원본 요구사항과 교육 기간 내 구현 가능성을 함께 고려해 결정한다.

**Decision**: 외부 분석 엔진을 연동할 수 있다. 현재 저장소는 Semgrep 연동을 우선 구현 후보로 두고, 분석 엔진을 처음부터 직접 구현하지 않는다. 외부 엔진의 결과를 KISA 기준에 매핑하는 어댑터와 자체 규칙이 필요한 경우의 확장 지점을 함께 둔다.

**Alternatives**: 자체 엔진 구현, 외부 분석 엔진 연동, 언어별 분석 도구 조합

**Consequences**: 외부 엔진을 선택하면 결과 파싱과 KISA 매핑이 필요하다. 지원 가능한 KISA 탐지 항목을 계속 늘리되, 엔진이 제공하지 않는 항목은 구현 상태를 구분해 표시한다. 어떤 방식을 선택하든 실행 시간 제한과 임시 작업영역 격리가 필요하다.
