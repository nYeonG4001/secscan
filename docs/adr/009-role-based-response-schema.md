# ADR-009: 역할별 분석 응답 스키마

## Context

SEC-003과 SEC-009는 분석 오류 정보와 로그를 관리자 권한으로 제한한다. 현재 공통 Analysis 응답에 `error_message`가 포함되면 일반 사용자에게 내부 정보가 노출될 수 있다.

## Decision

역할별 응답 모델을 분리한다.

- 일반 사용자 응답: 상태, 생성 시각, 시작·완료 시각, 일반적인 실패 안내
- 관리자 응답: 일반 사용자 필드와 함께 `error_message`, 상세 실행 정보, 권한 있는 원본 결과 정보

조건부 필드 마스킹보다 `AnalysisUserOut`과 `AnalysisAdminOut`처럼 명시적인 Pydantic 응답 모델을 사용한다. Finding의 `raw_result`도 관리자 전용 필드로 취급한다.

## Consequences

- API 계약만 읽어도 역할별 노출 범위를 확인할 수 있다.
- 분석 조회 라우트는 현재 사용자 역할에 맞는 응답 모델을 선택해야 한다.
- 프론트는 일반 사용자에게 내부 오류와 원본 분석 로그를 표시하지 않는다.
